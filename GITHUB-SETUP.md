# GitHub setup checklist (not part of the repo, keep for yourself)

## 1. Upload these files to the repo
```
index.html
README.md
LICENSE
assets/demo.gif
assets/screenshot-open.png
assets/screenshot-closed.png
assets/social-preview.png
```
Do not upload `GITHUB-SETUP.md`, `love-letter.html` or `send-love.html`.

## 2. Repo "About" box (gear icon, top right of the repo page)
**Description:**
Interactive love letter for long-distance couples. Open the envelope, read the note, catch hearts. Pure HTML, CSS and JS.

**Website:** paste your GitHub Pages link once it is live

**Topics (paste one by one):**
`love-letter` `long-distance-relationship` `valentines` `html` `css` `javascript` `vanilla-js` `web-animation` `github-pages` `single-file`

## 3. Turn on GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
Your link: https://YOUR-USERNAME.github.io/YOUR-REPO/ (takes 1 to 2 minutes to appear)

## 4. Social preview image
Settings → General → Social preview → Edit → Upload an image → choose `assets/social-preview.png` (1280 x 640).

## 5. Finish the README
Replace `YOUR-USERNAME` and `YOUR-REPO` in the demo link at the top of README.md.

## 6. Public or private?
GitHub Pages on a free account needs a public repo, so anyone can read the letter text.
Before making it public, change names and private wording in `index.html` if you want it personal only to her.
